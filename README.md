# 📷 QR / Barcode Scanner

Oddiy va qulay QR / Barcode skaner. [html5-qrcode](https://github.com/mebjas/html5-qrcode) kutubxonasi asosida yozilgan.  

🚀 **GitHub Pages orqali HTTPS** bilan ishlaydi, shuning uchun brauzer kamerani ochishga ruxsat beradi.  

---

## ⚡ Xususiyatlar
- QR va Barcode’larni real vaqtda skanerlash
- Oxirgi skaner natijasini ko‘rsatish
- 📋 Natijani **Copy** qilish
- 📤 Natijani to‘g‘ridan-to‘g‘ri Telegram botga yuborish

---

## 📂 Loyihaning tuzilishi
```
index.html   → Asosiy HTML fayl
style.css    → Dizayn (UI) uchun CSS
script.js    → Kamera va QR kod logikasi
README.md    → Loyihani tushuntiruvchi hujjat
```

---

## 🛠️ GitHub Pages’da deploy
1. Fayllarni GitHub reposiga yuklang  
2. Repo ichida **Settings → Pages** ga kiring  
3. `Branch: main` va `/ (root)` ni tanlang  
4. **Save** bosing  

🔗 Saytingiz manzili:
```
https://<username>.github.io/<repo>/
```
